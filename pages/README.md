# Эта папка намеренно пустая

В Feature-Sliced Design есть слой `pages`, а Next.js резервирует папку `pages/` для Pages Router.
Чтобы Next не принял `src/pages` за свой роутинг, в корне лежит эта пустая папка.

- Маршруты Next (App Router): `app/` в корне проекта — тонкие файлы, которые только реэкспортируют страницы.
- FSD-слой страниц: `src/pages/*`.
